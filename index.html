Three workflows. One pipeline.

Two move a candidate forward. The third watches both, so nothing fails quietly.

Intake form

Starts when someone applies

Checks the file is a PDF, blocks duplicate applications, saves the CV to Google Drive and adds a row to the applications sheet.

AI screening

Runs every hour

Reads each new CV, using OCR for scanned files. Scores it against the role, writes the score and decision back to the sheet, and emails the candidate. If the AI cannot decide, the row is marked for manual review and HR is notified.

Error handler

Runs alongside both

Logs every failure and emails an alert. Sends a digest at 8 AM, and checks every 2 hours that no application is stuck waiting.
